# Holberton School - Low Level Programming

## Description

Ce repository contient tous mes projets de programmation bas niveau en C réalisés à Holberton School.
Chaque dossier correspond à un concept fondamental du langage C.

---

## Contenu

| Dossier | Description |
|---|---|
| `hello_world` | Premiers pas en C : compilation, `printf`, `puts`, tailles des types |
| `variables_if_else_while` | Variables, conditions `if/else`, boucles `while` |
| `functions_nested_loops` | Fonctions, boucles imbriquées, `_putchar` |
| `more_functions_nested_loops` | Fonctions de vérification de caractères, formes géométriques, FizzBuzz |
| `pointers_arrays_strings` | Pointeurs, tableaux, manipulation de chaînes |
| `argc_argv` | Arguments de la ligne de commande avec `argc` et `argv` |
| `malloc_free` | Allocation dynamique avec `malloc` et `free` |
| `more_malloc_free` | Approfondissement de `malloc`, `realloc`, `calloc` |
| `structures_typedef` | Structures `struct`, `typedef`, gestion mémoire |
| `function_pointers` | Pointeurs de fonctions, passage de fonctions en paramètre |
| `variadic_functions` | Fonctions à nombre variable d'arguments (`va_list`) |
| `intro_debugging` | Introduction au debugging en C |
| `simple-calculator` | Calculatrice en ligne de commande avec pointeurs de fonctions |
| `benchmarking` | Comparaison de performances |

---

## Compétences acquises

- Compilation C avec `gcc` et ses différentes étapes
- Gestion manuelle de la mémoire (`malloc`, `free`)
- Manipulation de pointeurs et de chaînes de caractères
- Structures de données avec `struct` et `typedef`
- Fonctions avancées : variadiques et pointeurs de fonctions
- Passage d'arguments via le terminal (`argc`, `argv`)
