# 0x01 - Variables, if, else, while

## Ce que j'ai appris

Les bases du C : variables, conditions, boucles et fonctions simples.

---

## Les fichiers

| Fichier | Description |
|---|---|
| `0-putchar.c` | Affiche un caractère avec `_putchar` |
| `1-alphabet.c` | Affiche l'alphabet en minuscules |
| `2-print_alphabet_x10.c` | Affiche l'alphabet 10 fois |
| `3-islower.c` | Vérifie si un caractère est une minuscule |
| `4-isalpha.c` | Vérifie si un caractère est une lettre |
| `5-sign.c` | Affiche le signe d'un nombre (`+`, `-`, ou `0`) |
| `6-abs.c` | Retourne la valeur absolue d'un entier |
| `7-print_last_digit.c` | Affiche et retourne le dernier chiffre d'un nombre |
| `8-24_hours.c` | Affiche les minutes d'une journée (boucle 24h) |
| `9-times_table.c` | Affiche la table de multiplication de 9 |
| `10-add.c` | Additionne deux entiers |
| `11-print_to_98.c` | Affiche tous les nombres de `n` jusqu'à 98 |
