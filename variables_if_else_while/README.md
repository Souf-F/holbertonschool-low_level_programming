# 0x01 - Variables, if, else, while

## Ce que j'ai appris

Utiliser les variables, les boucles `while` et les conditions `if/else` pour afficher et manipuler des caractères et des chiffres en C.

---

## Les fichiers

| Fichier | Description |
|---|---|
| `0-positive_or_negative.c` | Affiche si un nombre aléatoire est positif, négatif ou zéro |
| `1-last_digit.c` | Affiche le dernier chiffre d'un nombre et sa nature |
| `2-print_alphabet.c` | Affiche l'alphabet en minuscules |
| `3-print_alphabets.c` | Affiche l'alphabet en minuscules puis en majuscules |
| `4-print_alphabt.c` | Affiche l'alphabet en minuscules sauf `q` et `e` |
| `5-print_numbers.c` | Affiche les chiffres de 0 à 9 |
| `6-print_numberz.c` | Affiche les chiffres de 0 à 9 sans utiliser `printf` avec `%d` |
| `7-print_tebahpla.c` | Affiche l'alphabet en sens inverse de `z` à `a` |
| `8-print_base16.c` | Affiche les chiffres hexadécimaux de `0` à `f` |
| `9-print_comb.c` | Affiche les chiffres de 0 à 9 séparés par des virgules |
